# Changelog

All notable changes to the "WooCommerce Create User from Guest Orders" plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-04-29

### Added
- Initial release
- "Create User from Guest" button in WooCommerce order edit screen
- JavaScript confirmation dialog for email sending preference
- User account creation from order billing information
- Username generation using firstname.lastname format with Norwegian character support
- Automatic reassignment of other guest orders with the same email
- Admin notices for operation feedback
- WooCommerce dependency check
- Localization support
