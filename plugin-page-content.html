WooCommerce Create User from Guest Orders

Convert guest orders into registered customer accounts with a single click

What is this plugin?

WooCommerce Create User from Guest Orders is a lightweight plugin that allows store administrators to convert guest orders into registered customer accounts directly from the WooCommerce Edit Order screen. With a single click, you can create a new user account using the customer's billing and shipping information, making it easier to manage customer relationships and provide a better shopping experience.

When would you use this plugin?

1. Converting phone orders to accounts

When customers place orders over the phone, you might enter them as guest orders. Later, you can easily convert these into proper customer accounts so they can log in and see their order history.

2. Helping customers who forgot to register

Many customers check out as guests for convenience but later wish they had created an account. Instead of asking them to register manually, you can create an account for them with all their information already filled in.

3. Consolidating customer data

When you notice the same guest email has placed multiple orders, you can convert one order to a user account and all other orders with the same email will automatically be reassigned to that account, giving you a complete view of that customer's purchase history.

4. Enabling subscription access

If a guest customer wants to access a subscription they purchased or convert a one-time purchase to a subscription, creating an account for them is the first necessary step.

5. Simplifying customer support

When providing support to guest customers, creating an account makes it easier to track their interactions and provide personalized service in the future.

Key Features

  • One-Click User Creation: Add a "Create User from Guest" button in the WooCommerce Edit Order admin screen.
  • Email Control: Choose whether to send login credentials to the new user.
  • Smart Username Generation: Creates usernames in the format firstname.lastname with proper handling of Norwegian characters (æ→ae, ø→oe, å→aa).
  • Complete Customer Data: Saves all billing and shipping information to the new user account.
  • Order Reassignment: Automatically finds and reassigns other guest orders with the same email address.
  • Clear Feedback: Shows success messages with details about the operation.

How It Works

  1. Navigate to a WooCommerce order that was placed by a guest (WooCommerce → Orders → Edit Order)
  2. Look for the "Create User from Guest" link next to the customer field
  3. Click the link and choose whether to send login credentials to the user
  4. The system will create a new user account, assign it to the current order, and reassign any other guest orders with the same email
  5. A success message will display with details about the operation

Installation

  1. Upload the woocommerce-create-user-from-guest folder to the /wp-content/plugins/ directory
  2. Activate the plugin through the 'Plugins' menu in WordPress
  3. Navigate to any guest order in WooCommerce to see the "Create User from Guest" button

Frequently Asked Questions

What happens if a user already exists with the same email?

The plugin checks if a user with the email already exists. If one does, it will abort the operation and display an error message.

How are usernames generated?

Usernames are created using the format firstname.lastname from the billing information. Norwegian characters are properly converted (æ→ae, ø→oe, å→aa). If a username already exists, a number is appended to ensure uniqueness.

Can I customize the email sent to users?

The plugin uses WordPress's built-in wp_new_user_notification() function to send emails. You can use plugins like "Email Customizer for WooCommerce" to modify these emails.

Will this work with my theme and other plugins?

The plugin is designed to be compatible with any WordPress theme and common WooCommerce extensions. It uses standard WooCommerce and WordPress hooks and functions.

Is there a way to automatically convert all guest orders?

Currently, the plugin is designed for manual conversion only. This is intentional to give administrators control over which guest orders should be converted to user accounts.
